## البنية
- app/: واجهات Next.js وواجهات API للمصادقة والمخزون والإدارة والحسابات والمطابقة والمختبر وMikroTik والتوقعات.
- server/: منطق المصادقة والتشفير والمعاملات وSQLite والتسليم والمطابقة والتحكم بالشبكات.
- drizzle/: ترحيلات SQL تطبق تلقائيًا عند فتح قاعدة البيانات.
- scripts/: الإدارة والنسخ والاستعادة واختبار HTTP وعاملا التسليم والتوقعات.
- tests/: ثمانية ملفات اختبارات Node، بإجمالي 53 اختبارًا.
- Dockerfile: Node 24 وبناء Next standalone وتشغيل مستخدم node.
- compose.yaml: التطبيق وعاملا الخلفية وCaddy وvolumes دائمة.
- pnpm-lock.yaml وpackageManager: تثبيت pnpm 11.25.0؛ يتطلب Node >=24 بسبب node:sqlite.
